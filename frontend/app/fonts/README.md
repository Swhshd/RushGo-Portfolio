# 本地 Geist 字体文件

[简体中文](README.md) | [English](README.en.md)

这两个拉丁字符集的 WOFF2 可变字体原样取自 Next.js 16.4.3 发行包中的 `next/dist/next-devtools/server/font/`。从本地加载后，前端继续使用 Geist Sans 和 Geist Mono，生产构建无需从 Google Fonts 下载文件。中文沿用现有的系统字体回退设置。

字体使用 SIL Open Font License 1.1。[仓库中的许可证原文](OFL.txt) · [Geist 字体项目](https://github.com/vercel/geist-font) · [许可证来源](https://raw.githubusercontent.com/vercel/geist-font/main/OFL.txt)

文件的 SHA-256 校验值如下。

- `geist-latin.woff2`：`1b5ebfb3a01a97343ac96873e6d59a8cb285c66012b6a1ac509cb2765e995ba8`
- `geist-mono-latin.woff2`：`b7ac144b394cbd81052d6397ec0c33397977b1d7e9bc095e744e652a378c6fb3`
