# Local Geist font assets

[简体中文](README.md) | [English](README.en.md)

These unmodified Latin variable WOFF2 assets were originally copied from the
Next.js 16.4.3 distribution under `next/dist/next-devtools/server/font/`.
They keep the existing Geist Sans and
Geist Mono families while removing Google Fonts downloads from production
builds. Chinese text continues to use the existing system-font fallback.
